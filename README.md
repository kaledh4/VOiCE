# رحلة الأبطال - تطبيق تعديل سلوك الأطفال 🌟

تطبيق تفاعلي ممتع يساعد الآباء والأمهات على تعديل سلوك أطفالهم من خلال محادثات ذكية مع شخصياتهم المفضلة.

## ✨ المميزات
- **محادثات ذكية**: مدعومة بالذكاء الاصطناعي (Hugging Face).
- **شخصيات متنوعة**: زوزو، إلسا، سبايدرمان، موانا، وعنتر.
- **سلوكيات إيجابية**: التركيز على النظافة، الاحترام، المذاكرة، وغيرها.
- **دعم PWA**: يمكن تثبيته كتطبيق مستقل على الهاتف.
- **تصميم عالمي**: واجهة مستخدم مبهجة ومناسبة للأطفال.

## 🚀 التشغيل المحلي
1. قم بتحميل المستودع.
2. انتقل إلى مجلد التطبيق: `cd child-behavior-app`
3. قم بتثبيت المكتبات: `npm install`
4. أنشئ ملف `.env` وأضف مفتاح Hugging Face:
   ```env
   VITE_HUGGINGFACE_TOKEN=your_token_here
   ```
5. ابدأ التشغيل: `npm run dev`

## 📦 النشر على GitHub
تم إعداد GitHub Actions للنشر التلقائي. تأكد من إضافة `VITE_HUGGINGFACE_TOKEN` في **GitHub Secrets**.

## 🛠️ التقنيات المستخدمة
- React + Vite
- Framer Motion (للأنيميشن)
- Lucide React (للأيقونات)
- Vite PWA Plugin
- Hugging Face Inference API
